GoPrometheusREST APIsMicroservices

The Challenge
Production incidents are hard to reason about without having seen what each failure mode looks like in metrics.

The Approach
Three independent Go services (user, order, payment) expose REST APIs and Prometheus metrics via middleware; Prometheus scrapes them alongside Windows host metrics.
